\chapter{Введение}

\section{Цель работы}

Освоить практические навыки работы с методами уменьшения размерности данных, такими как PCA (Principal Component Analysis) и t-SNE (t-distributed Stochastic Neighbor Embedding), а также интерпретации их результатов.

\section{Задачи работы}

\begin{enumerate}
    \item Провести предобработку данных о жанрах музыки
    \item Реализовать и применить метод главных компонент (PCA)
    \item Реализовать и применить метод t-SNE
    \item Провести сравнительный анализ методов PCA и t-SNE
\end{enumerate}

\section{Теоретические основы}

\textbf{Уменьшение размерности данных} -- это подход к упрощению сложных наборов данных путем сокращения количества переменных при сохранении наиболее важной информации. Это позволяет облегчить обработку, анализ и визуализацию данных.

\textbf{Метод главных компонент (PCA)} -- это линейный метод уменьшения размерности, который ищет направления максимальной дисперсии в данных. Он преобразует исходные переменные в новый набор некоррелированных переменных, называемых главными компонентами.

\textbf{t-SNE (t-distributed Stochastic Neighbor Embedding)} -- это нелинейный метод уменьшения размерности, который особенно эффективен для визуализации высокоразмерных данных. Он стремится сохранить локальную структуру данных, уделяя особое внимание сохранению близости между точками в пространстве меньшей размерности.

\chapter{Описание исходных данных и процесса их предобработки}

\section{Исходные данные}

Исходный датасет содержит информацию о музыкальных треках с различными аудио-характеристиками.

\textbf{Характеристики датасета:}
\begin{itemize}
    \item Общее количество записей: 50,005
    \item Количество признаков: 18
    \item Количество жанров: 11
    \item После предобработки: 45,020 записей с 12 числовыми параметрами
\end{itemize}

Датасет включает параметры: \texttt{popularity}, \texttt{acousticness}, \texttt{danceability}, \texttt{duration\_ms}, \texttt{energy}, \texttt{instrumentalness}, \texttt{key}, \texttt{liveness}, \texttt{loudness}, \texttt{mode}, \texttt{speechiness}, \texttt{tempo}, \texttt{valence}, \texttt{music\_genre} и другие.

\section{Предобработка данных}

\subsection{Замена нечисловых данных на числовые}

Были созданы шкалы соответствия для категориальных переменных: \texttt{key} (тональность C, C\#, D, ..., B $\to$ 0--11) и \texttt{mode} (Major $\to$ 1, Minor $\to$ 0).

\subsection{Удаление переменных с нулевой дисперсией}

Проведена проверка дисперсии всех числовых переменных. Переменные с нулевой дисперсией были удалены, так как они не несут информационной нагрузки.

\subsection{Отбор параметров}

Из всех доступных числовых параметров было отобрано 12 наиболее информативных: \texttt{popularity}, \texttt{acousticness}, \texttt{danceability}, \texttt{duration\_ms}, \texttt{energy}, \texttt{instrumentalness}, \texttt{key}, \texttt{liveness}, \texttt{loudness}, \texttt{mode}, \texttt{speechiness}, \texttt{tempo}.

\subsection{Корреляционная матрица}

\section{Реализация t-SNE}

Для реализации t-SNE использовалась библиотека \texttt{sklearn.manifold.TSNE}. Из-за вычислительной сложности t-SNE, анализ проводился на подвыборке данных (обычно 3000--5000 точек).

\section{Применение t-SNE с разными значениями перплексии}

\textbf{Перплексия (perplexity)} -- ключевой параметр t-SNE, определяющий баланс между локальной и глобальной структурой данных. Из-за вычислительной сложности анализ проводился на подвыборке из 5,000 записей.

Были протестированы значения: 5 (локальная структура), 30 (стандартное, оптимальный баланс), 50 и 100 (глобальная структура).

\section{Визуализации для разных значений перплексии}

\begin{figure}[H]
    \centering
    \includegraphics[width=0.95\textwidth]{images/tsne_perplexities.png}
    \caption{t-SNE с разными значениями перплексии}
    \label{fig:tsne_perplexities}
\end{figure}

\begin{figure}[H]
    \centering
    \includegraphics[width=0.9\textwidth]{images/tsne_optimal.png}
    \caption{Оптимальная t-SNE визуализация (перплексия = 30)}
    \label{fig:tsne_optimal}
\end{figure}

Анализ показывает: низкая перплексия (5) создает множество мелких кластеров, хорошо сохраняя локальную структуру; средняя (30) обеспечивает оптимальный баланс и лучше разделяет жанры; высокая (50--100) лучше сохраняет глобальную структуру, но может терять локальные детали. Для данного датасета оптимальной оказалась перплексия 30.

\section{Анализ влияния параметра перплексии на результат}

Перплексия влияет на размер кластеров (низкая -- больше мелких, высокая -- меньше крупных), разделимость жанров (оптимально 30--50), вычислительное время и стабильность результатов. Рекомендации: для небольших датасетов ($< 1000$) -- 5--15, для средних (1000--10000) -- 30--50, для больших ($> 10000$) -- 50--100.

\chapter{Сравнительный анализ PCA и t-SNE}

\section{Преимущества и недостатки каждого метода}

\subsection{PCA (Principal Component Analysis)}

\textbf{Преимущества:} быстрота вычислений, детерминированность, интерпретируемость, масштабируемость, обратимость, четкая метрика качества.

\textbf{Недостатки:} линейность (не улавливает нелинейные зависимости), фокус на глобальной структуре, ограниченная визуализация для нелинейных данных.

\subsection{t-SNE (t-distributed Stochastic Neighbor Embedding)}

\textbf{Преимущества:} нелинейность, отличное сохранение локальной структуры, информативные визуализации, лучшее разделение групп данных.

\textbf{Недостатки:} медленность вычислений, стохастичность результатов, требует подбора параметров, необратимость, искажение глобальных расстояний.

\section{Сравнение результатов на исследуемых данных}

\begin{figure}[H]
    \centering
    \includegraphics[width=0.95\textwidth]{images/pca_vs_tsne.png}
    \caption{Сравнение PCA и t-SNE}
    \label{fig:comparison}
\end{figure}

\textbf{На данных о музыкальных жанрах:}

\textbf{PCA:} выявляет основные направления вариации, позволяет интерпретировать важные характеристики, эффективен для понимания общей структуры данных.

\textbf{t-SNE:} лучше разделяет жанры на отдельные кластеры, создает более четкую визуализацию различий, показывает локальные сходства, может выявить скрытые подгруппы.

\textbf{Ключевые различия:} PCA показывает глобальную структуру и направления вариации, t-SNE -- локальную структуру и кластеризацию. Для разделения жанров t-SNE дает более информативную визуализацию, PCA лучше для понимания важности характеристик.

\section{Рекомендации по использованию методов для различных типов задач}

\textbf{PCA} рекомендуется для: исследовательского анализа данных, предобработки для машинного обучения, больших датасетов (когда важна скорость), случаев, когда важна интерпретируемость, данных с линейной структурой.

\textbf{t-SNE} рекомендуется для: визуализации сложных нелинейных данных, кластеризации и разделения групп, небольших и средних датасетов, презентации результатов.

\textbf{Комбинированное использование:} эффективно применять PCA для уменьшения размерности до 50--100 компонент, затем t-SNE для финальной визуализации, или использовать PCA для анализа структуры, а t-SNE для презентации результатов.

\chapter{Выводы по работе}

\begin{enumerate}
    \item Предобработка данных (обработка категориальных переменных, удаление неинформативных признаков, стандартизация) критически важна для успешного применения методов уменьшения размерности.
    
    \item PCA эффективен для быстрого анализа структуры данных, выявления основных направлений вариации, интерпретации важности характеристик и работы с большими объемами данных.
    
    \item t-SNE превосходит PCA в визуализации сложных нелинейных структур, разделении классов, сохранении локальной структуры и создании информативных визуализаций.
    
    \item Выбор метода зависит от задачи: PCA -- для понимания структуры и интерпретации, t-SNE -- для визуализации и кластеризации, комбинация -- для комплексного анализа.
    
    \item Параметры методов (количество компонент для PCA, перплексия для t-SNE) требуют тщательного подбора в зависимости от характеристик данных и целей анализа.
\end{enumerate}
