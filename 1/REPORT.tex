\chapter{Реализация и применение t-SNE}

t-SNE (t-distributed Stochastic Neighbor Embedding) -- нелинейный метод, который фокусируется на сохранении локальных расстояний между точками. В отличие от PCA, он особенно хорошо подходит для визуализации кластерной структуры. Перплексия (perplexity) -- важнейший параметр t-SNE, который определяет баланс между вниманием к локальной и глобальной структуре данных.

\section{Подготовка данных}

\begin{lstlisting}
# Ограничиваем размер данных для t-SNE 
# (может быть медленным для больших наборов)
if X_scaled.shape[0] > 2000:
    # Берем случайную выборку для визуализации
    np.random.seed(42)
    indices = np.random.choice(X_scaled.shape[0], 
                               5000, replace=False)
    X_tsne = X_scaled[indices]
    y_tsne = y.iloc[indices]
else:
    X_tsne = X_scaled
    y_tsne = y
print(f"Размер данных для t-SNE: {X_tsne.shape}")
\end{lstlisting}

\section{Применение t-SNE с разными значениями перплексии}

\begin{lstlisting}
# Применяем t-SNE с разными значениями перплексии
perplexities = [5, 30, 50, 100]
tsne_results = {}
for perplexity in perplexities:
    print(f"Вычисление t-SNE с перплексией={perplexity}...")
    tsne = TSNE(n_components=2, perplexity=perplexity, 
                max_iter=1000)
    X_tsne_proj = tsne.fit_transform(X_tsne)
    tsne_results[perplexity] = X_tsne_proj

# Визуализация результатов t-SNE
plt.figure(figsize=(20, 5))
for i, perplexity in enumerate(perplexities, 1):
    plt.subplot(1, 4, i)
    X_tsne_proj = tsne_results[perplexity]
    scatter = plt.scatter(X_tsne_proj[:, 0], 
                         X_tsne_proj[:, 1], 
                         c=y_tsne, cmap='viridis', 
                         alpha=0.7, s=30)
    plt.xlabel('t-SNE 1')
    plt.ylabel('t-SNE 2')
    plt.title(f't-SNE (перплексия={perplexity})')
    plt.colorbar(scatter, label='Музыкальный жанр')
    plt.grid(True, alpha=0.3)
plt.show()
\end{lstlisting}

\chapter{Сравнительный анализ PCA и t-SNE}

\section{Преимущества методов}

\subsection{PCA (Principal Component Analysis)}

\textbf{Преимущества:}
\begin{itemize}
    \item Высокая скорость работы -- алгоритм выполняется за секунды даже для больших наборов данных благодаря линейной природе преобразования
    \item Отличная интерпретируемость -- главные компоненты имеют четкую математическую интерпретацию и могут быть выражены через исходные переменные
    \item Сохранение глобальной структуры -- PCA оптимально сохраняет глобальные расстояния и дисперсию данных в новом пространстве
    \item Минимальное количество гиперпараметров -- основной параметр (количество компонент) легко определяется по графику каменистой осыпи
    \item Полная воспроизводимость -- результаты детерминированы и полностью воспроизводимы при повторных запусках
    \item Хорошая масштабируемость -- эффективно работает с данными высокой размерности
\end{itemize}

\subsection{t-SNE (t-distributed Stochastic Neighbor Embedding)}

\textbf{Преимущества:}
\begin{itemize}
    \item Отличное сохранение локальной структуры -- метод специально разработан для выявления и сохранения локальных кластеров и соседних отношений
    \item Эффективность для нелинейных данных -- успешно работает с данными, имеющими сложные нелинейные зависимости
    \item Визуальная привлекательность -- результаты часто дают четкие и интерпретируемые визуализации кластеров
    \item Выявление сложных структур -- способен обнаруживать кластеры сложной формы и неявные закономерности
\end{itemize}

Для задачи классификации музыкальных жанров оба метода показали различную эффективность. Выбор метода должен определяться конкретными целями анализа: PCA для общего исследования структуры данных, t-SNE для детального изучения кластерных образований.

\chapter{Выводы по работе}

\begin{enumerate}
    \item Предобработка данных (обработка категориальных переменных, удаление неинформативных признаков, стандартизация) критически важна для успешного применения методов уменьшения размерности.

    \item Выбор метода зависит от задачи: PCA -- для понимания структуры и интерпретации, t-SNE -- для визуализации и кластеризации, комбинация -- для комплексного анализа.
    
    \item Параметры методов (количество компонент для PCA, перплексия для t-SNE) требуют тщательного подбора в зависимости от характеристик данных и целей анализа.
\end{enumerate}
