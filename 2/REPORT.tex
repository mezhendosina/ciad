\section{Теоретические основы}

\textbf{Кластеризация} -- это метод машинного обучения без учителя, направленный на разделение набора объектов на группы (кластеры) таким образом, чтобы объекты внутри одной группы были более похожи друг на друга, чем на объекты из других групп.

\textbf{Метод K-средних} -- это итеративный алгоритм, который разбивает набор данных на K предопределенных непересекающихся подгрупп (кластеров), где каждая точка данных принадлежит только одному кластеру. Алгоритм работает следующим образом:
\begin{enumerate}
    \item Инициализирует K центроидов случайным образом
    \item Назначает каждую точку ближайшему центроиду
    \item Пересчитывает позиции центроидов как среднее значение точек в кластере
    \item Повторяет шаги 2--3 до сходимости
\end{enumerate}

\textbf{Метод DBSCAN} (Density-Based Spatial Clustering of Applications with Noise) -- это алгоритм кластеризации, основанный на плотности. Он группирует вместе точки, которые находятся близко друг к другу в областях высокой плотности, отмечая точки в областях с низкой плотностью как выбросы. Основные параметры:
\begin{itemize}
    \item \texttt{eps} (epsilon) -- максимальное расстояние между точками одного кластера
    \item \texttt{min\_samples} -- минимальное количество точек для формирования кластера
\end{itemize}

\section{Применение метода K-средних}

\subsection{Определение оптимального количества кластеров}

Для определения оптимального количества кластеров использовались два метода:
\begin{enumerate}
    \item \textbf{Метод локтя (Elbow Method)} -- анализ зависимости инерции (суммы квадратов расстояний от точек до центроидов) от количества кластеров
    \item \textbf{Коэффициент силуэта (Silhouette Score)} -- метрика, оценивающая качество кластеризации на основе того, насколько хорошо точки разделены на кластеры
\end{enumerate}

\begin{figure}[H]
    \centering
    \includegraphics[width=0.9\textwidth]{images/synthetic_elbow_silhouette.png}
    \caption{Метод локтя и коэффициент силуэта для определения оптимального K}
    \label{fig:elbow_silhouette}
\end{figure}

Результаты анализа:
\begin{itemize}
    \item \textbf{Оптимальное K по методу локтя}: 5 (видно из графика, где происходит ``излом'' кривой)
    \item \textbf{Оптимальное K по коэффициенту силуэта}: 4
    \item \textbf{Максимальный коэффициент силуэта}: 0.7328
\end{itemize}

Интересно отметить, что метод локтя указывает на 5 кластеров (что соответствует истинному количеству), в то время как коэффициент силуэта максимизируется при K=4. Это демонстрирует, что разные метрики могут давать разные результаты, и важно использовать несколько методов оценки.

\subsection{Результаты кластеризации K-means}

Было выбрано оптимальное значение K=4 (по коэффициенту силуэта) для дальнейшего анализа.

        \item Для K-means критически важно правильно выбрать K (метод локтя и коэффициент силуэта помогают)
        \item Для DBSCAN критически важно правильно выбрать \texttt{eps} и \texttt{min\_samples}
        \item Неправильный выбор параметров может привести к плохим результатам
    \end{itemize}
\end{enumerate}

\section{Преимущества и недостатки методов}

\textbf{K-means:}
\begin{itemize}
    \item \textbf{Преимущества}: Простота, скорость, интерпретируемость
    \item \textbf{Недостатки}: Требует знания количества кластеров, работает только с шарообразными кластерами
\end{itemize}

\textbf{DBSCAN:}
\begin{itemize}
    \item \textbf{Преимущества}: Не требует знания количества кластеров, находит кластеры произвольной формы, устойчив к выбросам
    \item \textbf{Недостатки}: Сложность настройки параметров, может быть медленным на больших данных
\end{itemize}

\section{Рекомендации по применению}

\begin{enumerate}
    \item \textbf{Используйте K-means, когда:}
    \begin{itemize}
        \item Известно или можно оценить количество кластеров
        \item Кластеры имеют шарообразную форму
        \item Нужна быстрая кластеризация
        \item Данные не содержат много выбросов
    \end{itemize}
    
    \item \textbf{Используйте DBSCAN, когда:}
    \begin{itemize}
        \item Количество кластеров неизвестно
        \item Кластеры могут иметь произвольную форму
        \item В данных есть выбросы
        \item Важно найти кластеры на основе плотности
    \end{itemize}
\end{enumerate}

\section{Заключение}

В ходе лабораторной работы были успешно применены два метода кластеризации -- K-means и DBSCAN -- на синтетических и реальных данных. Оба метода показали свои сильные и слабые стороны:

\begin{itemize}
    \item \textbf{K-means} оказался более простым в использовании и интерпретации, но требует предварительного знания количества кластеров
    \item \textbf{DBSCAN} показал лучшие результаты на синтетических данных и более гибкий подход к определению количества кластеров, но требует тщательной настройки параметров
\end{itemize}

Выбор метода зависит от конкретной задачи, характеристик данных и требований к результатам кластеризации.
